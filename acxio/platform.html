Platform

From the first word to a person.

A message is saved, named, and answered. The team sees the same thread the agent just touched. Nothing waits in another app.

The path

Four moves. Then the desk holds it.

01 Arrive

A message lands on the desk as soon as the customer sends, from WhatsApp, Messenger, Instagram, the website, email, SMS, Telegram, Line, or another connected channel.

02 Name

The sender is stored with a real name when the channel can give one. The list stays human.

03 Reply

The agent writes the first line. A person continues in the same window, with the history intact.

04 Hold

Mine, unassigned, and all keep the day’s work visible. The thread does not depend on one tab staying open.

On a Monday

The queue is shorter because someone already answered.

Hours, stock, and simple questions do not need a person for the first line. The agent writes it. What remains is a decision, a booking, or a name.

A WhatsApp thread and a Messenger thread are handled the same way: open, owned, and answered in the window beside this text.

See
Who is waiting

The list shows the channel, the person, and the last line. Unassigned work is obvious. Mine is the work already taken.

Hand
Off without losing the story

When a person steps in, the agent’s reply is already in the thread. They continue it. The customer sees one conversation.

Send

The answer returns on the channel it arrived on. It does not become a new chat in another tool.
